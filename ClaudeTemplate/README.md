# Claude Template

`CLAUDE.md` is distributed to the consumer project root. Its source and destination are defined only in
[`../AgentEntry/AgentTemplateManifest.json`](../AgentEntry/AgentTemplateManifest.json); do not duplicate that mapping in the UI or installer.

`CLAUDE.local.md` is an optional project-specific opt-in template. It is not managed by the entry-document installer.
