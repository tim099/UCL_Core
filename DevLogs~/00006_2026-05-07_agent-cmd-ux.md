# Agent Command UX — Fill Example 按鈕 + Failed 自動清理 + Clear Failed 按鈕

## What

三個小但有感的 Agent Command 操作改善：

1. **`UCL_AgentCommandHandlerBase.ExampleArgs`**（新虛擬屬性）— 子類覆寫提供「一鍵填入即可執行」的範例 args（`k=v;k=v` 格式）。
2. **UCL_AgentCommandsPage 加 Fill Example 按鈕** — Args 欄位旁，點下去把選定 Cmd 的 `ExampleArgs` 直接灌入，無範例的 Cmd 按鈕自動 disabled。
3. **Python wrapper 失敗自動清理** — `run_cmd.py` 偵測到 `LastRunResult=Failed` 時，預設**自動把該 cmd 從 queue.json 移除**並印 stderr 通知，下次 batch 不會再被卡。`--keep-failed` 旗標可保留條目除錯用。
4. **UCL_AgentCommandsPage 加 Clear Failed 按鈕** — 一鍵清空 queue 內所有 LastRunResult=Failed 條目（給歷史殘留 / 別人留下的失敗條目用）。

內建 7 個 Cmd 都已補上 `ExampleArgs`（DebugLog / Ping / ExportNotes / ResolveAssetReferences / FindAssetUsages / ExportCommandCatalog / ValidateAssetFormat）。

## Why

舊版兩個痛點：
- 試新 Cmd 要先翻文件抄 args schema 才能跑 — 對「想快速看這 Cmd 做什麼」的人摩擦很高
- OneShot Cmd 失敗會留在 queue 等 retry，但若是 Type 拼錯之類的死局，留著只會每次 Run 都失敗 → agent / 人類體感「每次都卡住」

## How to use

### 為自家 Cmd 補 ExampleArgs

```csharp
public class Cmd_DoublePriceByRarity : UCL_AgentCommandHandlerBase
{
    public override string CommandType => "DoublePriceByRarity";
    public override string ArgsSchema => "rarity=Rarity_Bronze | Rarity_Silver | Rarity_Gold";

    /// <summary>Page「Fill Example」按鈕一鍵填入用</summary>
    public override string ExampleArgs => "rarity=Rarity_Bronze";

    public override async UniTask ExecuteAsync(...) { ... }
}
```

### Python wrapper 行為

```bash
# 預設：失敗自動移除
python run_cmd.py run NonExistentCmd        # → exit 2，cmd 自動從 queue 移除

# 想留條目除錯
python run_cmd.py run BadCmd --keep-failed  # → exit 2，cmd 保留在 queue 帶 LastRunError
```

### Editor UI Clear Failed

`UCL_AgentCommandsPage` TopBar 多一顆橘色「Clear Failed」按鈕，點下去清空所有 Failed 條目（不影響 Pending / Success / Repeatable）。
