# UCL_ModuleEditPage (モジュール編集ページ)

## 1. システム概要
`UCL_ModuleEditPage` は、UCL フレームワークにおいて単一のモジュール（Module）の詳細設定、アセットの保守、およびライフサイクル管理を行うための専用編集インターフェースです。このページを通じて、開発者はモジュールのファイルシステムを直感的に操作し、含まれるすべてのアセットデータを編集できます。

## 2. インターフェース機能詳細

### 2.1 トップバー (Top Bar)
*   **戻る/閉じる**：現在の編集を終了し、モジュール管理メインページに戻ります。
*   **[ModuleID]**：現在編集中的モジュールの識別子を表示します。
*   **モジュールフォルダを開く**：モジュールのソース/リソースルートディレクトリをエクスプローラーで直接開きます。
*   **インストールフォルダを開く**：モジュールがシステムにインストールされた後のターゲットディレクトリを開きます。
*   **RefreshAllDatas(With Reflection)**：リフレクションメカニズムを使用してプロジェクト内のすべてのアセットを強制的に再スキャンし、データの同期問題を解決します。

### 2.2 ライフサイクル操作 (Lifecycle Controls)
*   **Zip Module**：モジュールを `.zip` 形式にパッケージ化し、配布やバックアップを容易にします。
*   **Save Module**：インターフェース上のすべての変更をモジュールの実体 JSON 設定ファイルに保存します。
*   **Load Module**：現在の変更を破棄し、ディスクからモジュールの元データを再読み込みします。
*   **Install Module**：モジュールを実行環境にインストールします（アセットのロード、サービスの登録など）。
*   **UnInstall Module**：モジュールを実行環境からアンインストールし、リソースを解放します。

### 2.3 コア編集エリア (Content Area)
*   **CurEditModule (展開メニュー)**：
    *   **設定 (Settings)**：
        *   `Version`：モジュールのバージョン番号。
        *   `LastEditTime`：最後にモジュール設定を編輯した時間（保存時にシステムによって自動的に生成されます）。
        *   `UTC_TimeStamp`：グローバルタイムスタンプ（モジュールの再インストールが必要かどうかを判断するためにシステム内部で使用されます）。
        *   `ID`：モジュールの固有 ID（理論的にはモジュールフォルダ名と一致します）。
        *   `Title`：モジュールの表示名（主に Steam ワークショップで使用されます）。
        *   `Description`：モジュールの詳細な説明。
        *   `DependenciesModules`：このモジュールが依存している他のモジュールをリストします。
    *   **Logo 設定**：
        *   システムはモジュールのルートディレクトリにある **`Logo.png`** ファイルをモジュールのアイコンとして自動的に読み取ります。
        *   **設定方法**：準備した画像を `Logo.png` という名前でモジュールのルートフォルダに配置してください。
        *   インターフェースで `Logo` セクションを展開すると、リアルタイムでプレビューできます。
    *   **モジュール內容**：
        *   **アセットグループ化**：アセットカテゴリ（Data, Logic, UI など）に基づいて自動的に分類されます。
        *   **アセット編輯エントリ**：モジュール内に作成されたすべてのアセット（例：`UCL_CSVAsset`）を表示します。「編輯」をクリックすると、そのアセット専用のエディタに入ります。

### 2.4 フッター
*   **Export Module**：モジュールのエクスポートプロセスを実行し、最終的なリリースアセットの準備に使用されます。

## 3. 注意事項
> [!IMPORTANT]
> 重大な変更を行った後は、必ず **Save Module** をクリックして変更がハードディスクに書き込まれたことを確認してください。変更がアセット定義やパスの変更に関わる場合は、保存後に **RefreshAllDatas** を執行してシステムの状態を一致させることを推奨します。
