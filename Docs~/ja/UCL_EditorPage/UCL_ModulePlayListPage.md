# UCL_ModulePlayListPage (モジュールプレイリスト管理ページ)

## 1. システム概要
`UCL_ModulePlayListPage` は、`UCL_ModulePlaylist`（モジュールプレイリスト）を管理するための専用エディタページです。開発者が異なるモジュールロードの組み合わせを複数定義できるようにし、テスト、環境の切り替え、または異なるバージョンの Mod コレクションの配布を容易にします。

## 2. コア機能
*   **リスト選択 (Playlist Selection)**: `PersistentDataPath` 下に保存されているすべての `.json` 形式のプレイリストを表示します。
*   **動的作成**: 新しいプレイリストを素早く作成できます（デフォルトで必要な `Core` コアモジュールが含まれます）。
*   **即時ロード**: 「Load current playlist」ボタンを提供し、`LoadModulePlaylistAsync` を呼び出して直ちにモジュールサービスを再初期化します。
*   **編集モードの切り替え**:
    *   **Select モード**: プレイリストの選択と作成を行います。
    *   **Edit モード**: ロード順序や有効状態を含むリスト内容を編集します。

## 3. 操作フロー
1.  **ページへのアクセス**: 通常、`UCL_ModuleService` のメインページから「プレイリスト管理」をクリックしてアクセスします。
2.  **編集と保存**: リスト内で必要なモジュールにチェックを入れ、順序を調整してから「Save」をクリックして設定を永続化します。
3.  **適用の実行**: 「Load current playlist」をクリックすると、システムは現在ロードされているモジュールをクリアし、新しいリストに従ってリロードします。

## 4. 主要コンポーネント
*   **`UCL_ModulePlaylist`**: モジュール ID リストとロードロジックを定義するデータ実体クラス。
*   **`UCL_ModuleService.LoadModulePlaylistAsync`**: コアなロードパイプラインを実行する非同期メソッド。

> [!IMPORTANT]
> プレイリストを変更すると、現在ロードされているすべての `UCL_Module` インスタンスが解放され、再生成されます。切り替える前に、実行中の重要なロジックがないことを確認してください。
