# UCL_SelectAssetPage (アセット選択ページ)

## 1. システム概要
`UCL_SelectAssetPage` は、UCL フレームワークにおいて特定のタイプのアセット（Asset）を管理するためのコアナビゲーションページです。構造化されたリストを提供し、開発者がモジュール内のさまざまなデータアセットを迅速に検索、プレビュー、編集、または削除できるようにします。

## 2. インターフェース機能詳細

### 2.1 トップ機能列 (Top Bar)
*   **[アセット名] を作成**：クリックすると `UCL_CreateAssetPage` に移動し、そのタイプのリソースを新規作成します。
*   **RefreshData**：ディスクファイルを再スキャンし、リスト内のデータが実際のファイルと同期していることを確認します。
*   **OpenFolder**：OS のエクスプローラーで、そのタイプのアセットの保存ディレクトリを直接開きます。
*   **ヘルプボタン (?)**：アセットクラスに `[HelpURL]` 属性が定義されている場合、リンクボタンが表示されます。
*   **クラス名をコピー**：現在のアセットタイプの完全な C# クラス名をクリップボードにコピーします。

### 2.2 アセットリストと検索 (Asset List & Search)
*   **検索バー (Search)**：正規表現 (Regex) による曖昧検索をサポートしています。一致するテキストは赤色で強調表示されます。
*   **ページング制御 (Pagination)**：
    *   デフォルトで 1 ページあたり 10 個のアセットを表示します。
    *   「前へ/次へ」ボタンと、ページ番号を直接入力してジャンプする機能を提供します。

### 2.3 リスト項目アクション (List Item Actions)
*   **アセット ID/名前**：アセットの固有 ID またはローカライズされた名前を表示します。
*   **Edit (編集)**：そのアセット専用の編集ページ (`UCL_CommonEditPage`) を開きます。
*   **Preview (プレビュー)**：編集ページに移動することなく、ページの右側にアセットの内容のスナップショットを表示します。
*   **Delete (削除)**：確認ダイアログの後にアセットファイルを削除します。
*   **グループ編集 (Group Edit)**：Meta 管理が有効な場合、リスト内でアセットのグループ情報を直接変更できます。

### 2.4 右側プレビューエリア (Preview Area)
リストの「Preview」ボタンをクリックすると、アセットに実装された `Preview` ロジックに基づいて、詳細な内容（CSV テーブルデータ、Sprite 画像など）が右側に表示されます。

## 3. 開発者設定

### 3.1 說明文との関連付け (HelpURL)
開発者は、アセットクラスに `[HelpURL]` 属性を追加することで、このページのヘルプボタンを特定のドキュメントに向けることができます。

```csharp
[HelpURL("ucl_core:Docs~/{lang}/API/UCL_Asset/MyCustomAsset.md")]
public class MyCustomAsset : UCL_CSVAsset { ... }
```

## 4. 注意事項
> [!TIP]
> アセットの数が多い場合は、**Search** と **Pagination** を活用して管理効率を大幅に向上させてください。新しく作成したファイルがリストに表示されない場合は、**RefreshData** をクリックしてください。
