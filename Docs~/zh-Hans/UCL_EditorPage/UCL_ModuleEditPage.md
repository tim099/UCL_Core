# UCL_ModuleEditPage (模块编辑页面)

## 1. 系统概觀
`UCL_ModuleEditPage` 是 UCL 框架中用于对单一模块（Module）进行详细设定、资产维护与生命周期管理的专属编辑界面。通过此页面，开发者可以直觀地操作模块的文件系统，并编辑其包含的所有资产数据。

## 2. 界面功能详解

### 2.1 顶部工具栏 (Top Bar)
*   **返回/关闭**：结束当前编辑，返回至模块管理主页面。
*   **[ModuleID]**：显示当前正在编辑的模块识别码。
*   **开启模块文件夹**：直接在文件管理器中开启该模块的源代码/资源根目录。
*   **开启安装文件夹**：开启该模块被安装至系统后的目标目录。
*   **RefreshAllDatas(With Reflection)**：强制通过反射机制重新扫描并更新项目中所有资产的状态，用于解决数据同步问题。

### 2.2 模块生命周期操作 (Lifecycle Controls)
*   **Zip Module**：将模块封装成 `.zip` 格式，便于分发或备份。
*   **Save Module**：将当前界面上的所有修改保存回模块的实体 JSON 配置文件。
*   **Load Module**：放弃当前修改，重新从磁盘读取模块的原始数据。
*   **Install Module**：将模块安装至运行环境（如加载资产、注册服务等）。
*   **UnInstall Module**：从运行环境中卸载该模块，释放资源。

### 2.3 核心编辑区块 (Content Area)
*   **CurEditModule (展开菜单)**：
    *   **设定 (Settings)**：
        *   `Version`：模块的版本编号。
        *   `LastEditTime`：上次编辑模块配置的时间（由系统在保存时自动产生）。
        *   `UTC_TimeStamp`：全球标准时间戳（系统内部用来判断模块是否需要重新安装）。
        *   `ID`：模块的唯一识别码（理论上与模块文件夹名称一致）。
        *   `Title`：模块的显示名称（主要显示于 Steam 工坊）。
        *   `Description`：模块的详细描述信息。
        *   `DependenciesModules`：列出此模块所依赖的其他模块（加载时会优先确保依赖项存在）。
    *   **Logo 设定**：
        *   系统会自动读取模块根目录下的 **`Logo.png`** 文件作为模块图标。
        *   **设定方法**：将准备好的图片命名为 `Logo.png` 并放入该模块的根文件夹内。
        *   在界面中展开 `Logo` 区块即可实时预览。
    *   **模块内容**：
        *   **Asset 分组**：根据资产类别（如 Data, Logic, UI 等）自动进行分类。
        *   **资产编辑入口**：列出该模块下所有已建立的资产（如 `UCL_CSVAsset`），点击“编辑”即可进入该资产的专属编辑器。

### 2.4 底端功能
*   **Export Module**：执行模块导出流程，通常用于准备最终发布资源。

## 3. 注意事项
> [!IMPORTANT]
> 在进行重大修改后，请务必点击 **Save Module** 确保变更已写入硬盘。若修改涉及资产定义或路径变更，建议在保存后执行 **RefreshAllDatas** 以确保系统状态一致。
