# UCL_ModuleServiceEditPage (模块服务编辑页面)

## 1. 界面概览
`UCL_ModuleServiceEditPage` 是 UCL 模块系统的核心管理界面。开发者在此可以切换编辑模式、管理模块配置、创建新模块，以及进入播放清单管理流程。

## 2. 核心功能区块

### 2.1 全局管理
*   **编辑模式 (Edit Mode)**：切换目前系统运作的资源环境。
    *   `Builtin`：处理内置模块（通常位于 `StreamingAssets`）。
    *   `Runtime`：处理运行时模块（位于 `PersistentDataPath`，支持 Modding）。
*   **配置操作**：提供“保存设置”与“载入设置”功能。
*   **路径访问**：提供“开启模块文件夹”按钮，快速定位物理文件位置。

### 2.2 模块维护
*   **创建新模块**：建立全新的模块文件夹与设置。
*   **模块编辑入口**：
    *   通过下拉菜单选择目标模块 ID（例如 `Core`）。
    *   点击 **“编辑”** 按钮进入该模块的细节设置页面（`UCL_ModuleEditPage`）。

### 2.3 播放清单管理 (Playlist Management)
*   **编辑播放集**：点击按钮开启 `UCL_ModulePlayListPage`。
*   **运作逻辑提示**：若要启用特定模块，必须将其加入播放清单中。系统会按清单顺序加载模块，**后加载的模块会覆盖前者的同 ID 资产**。

### 2.4 运行时状态检视
*   **目前载入的模块**：展开后可查看当前系统已激活的模块实例。
*   **AssetsCache**：显示资产缓存字典的状态，用于开发调试路径解析。

## 3. 注意事项
> [!WARNING]
> 对 `Builtin(Core)` 的直接编辑在系统更新后可能会失效。建议建立新的模块来新增或覆盖原有内容。

> [!TIP]
> 善用“复制”按钮可快速取得当前页面的数据路径，方便在脚本中进行除错。
