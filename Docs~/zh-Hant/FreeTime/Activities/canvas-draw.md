# 繪圖 (共用像素畫布)

在 2048×2048 共用像素畫布放點 / 看全貌 / 宣稱區域。自由時間特典: 每場發 10 顆免費像素 (Cmd_FreeTime step=start 發放; pay=auto 自動優先用免費額度, 用不完歸零)。

- Skill: `ucl-canvas`
- CLI: `python <UCL_Core>/Tools~/AgentCommands/canvas.py place --x --y --color --persona <me>`
- 設計: `docs/Plan/Plan_Shared_Pixel_Canvas.md`
