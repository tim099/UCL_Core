# UCL_ModuleEditPage (模組編輯頁面)

## 1. 系統概觀
`UCL_ModuleEditPage` 是 UCL 框架中用於對單一模組（Module）進行詳細設定、資產維護與生命週期管理的專屬編輯介面。透過此頁面，開發者可以直觀地操作模組的檔案系統，並編輯其包含的所有資產數據。

## 2. 介面功能詳解

### 2.1 頂部工具列 (Top Bar)
*   **返回/關閉**：結束當前編輯，返回至模組管理主頁面。
*   **[ModuleID]**：顯示當前正在編輯的模組識別碼。
*   **開啟模組資料夾**：直接在檔案總管中開啟該模組的原始碼/資源根目錄。
*   **開啟安裝資料夾**：開啟該模組被安裝至系統後的目標目錄。
*   **RefreshAllDatas(With Reflection)**：強制透過反射機制重新掃描並更新專案中所有資產的狀態，用於解決數據同步問題。

### 2.2 模組生命週期操作 (Lifecycle Controls)
*   **Zip Module**：將模組封裝成 `.zip` 格式，便於分發或備份。
*   **Save Module**：將當前介面上的所有修改儲存回模組的實體 JSON 配置檔案。
*   **Load Module**：放棄當前修改，重新從磁碟讀取模組的原始數據。
*   **Install Module**：將模組安裝至運行環境（如載入資產、註冊服務等）。
*   **UnInstall Module**：從運行環境中解除安裝該模組，釋放資源。

### 2.3 核心編輯區塊 (Content Area)
*   **CurEditModule (展開選單)**：
    *   **設定 (Settings)**：
        *   `Version`：模組的版本編號。
        *   `LastEditTime`：上次編輯模組配置的時間（由系統在存檔時自動產生）。
        *   `UTC_TimeStamp`：全球標準時間戳記（系統內部用來判斷模組是否需要重新安裝）。
        *   `ID`：模組的唯一識別碼（理論上與模組資料夾名稱一致）。
        *   `Title`：模組的顯示名稱（主要顯示於 Steam 工作坊）。
        *   `Description`：模組的詳細描述資訊。
        *   `DependenciesModules`：列出此模組所依賴的其他模組（載入時會優先確保依賴項存在）。
    *   **Logo 設定**：
        *   系統會自動讀取模組根目錄下的 **`Logo.png`** 檔案作為模組圖示。
        *   **設定方法**：將準備好的圖片命名為 `Logo.png` 並放入該模組的根資料夾內。
        *   在介面中展開 `Logo` 區塊即可即時預覽。
    *   **模組內容**：
        *   **Asset 分組**：根據資產類別（如 Data, Logic, UI 等）自動進行分類。
        *   **資產編輯入口**：列出該模組下所有已建立的資產（如 `UCL_CSVAsset`），點擊「編輯」即可進入該資產的專屬編輯器。

### 2.4 底端功能
*   **Export Module**：執行模組匯出流程，通常用於準備最終發布資源。

## 3. 注意事項
> [!IMPORTANT]
> 在進行重大修改後，請務必點擊 **Save Module** 確保變更已寫入硬碟。若修改涉及資產定義或路徑變更，建議在存檔後執行 **RefreshAllDatas** 以確保系統狀態一致。
