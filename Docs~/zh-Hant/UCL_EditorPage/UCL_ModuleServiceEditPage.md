# UCL_ModuleServiceEditPage (模組服務編輯頁面)

## 1. 介面概覽
`UCL_ModuleServiceEditPage` 是 UCL 模組系統的核心管理介面。開發者在此可以切換編輯模式、管理模組配置、建立新模組，以及進入播放清單管理流程。

## 2. 核心功能區塊

### 2.1 全域管理
*   **編輯模式 (Edit Mode)**：切換目前系統運作的資源環境。
    *   `Builtin`：處理內建模組（通常位於 `StreamingAssets`）。
    *   `Runtime`：處理執行時模組（位於 `PersistentDataPath`，支援 Modding）。
*   **配置操作**：提供「保存設定」與「載入設定」功能。
*   **路徑存取**：提供「開啟模組資料夾」按鈕，快速定位物理檔案位置。

### 2.2 模組維護
*   **創建新模組**：建立全新的模組資料夾與設定。
*   **模組編輯入口**：
    *   透過下拉選單選擇目標模組 ID（例如 `Core`）。
    *   點擊 **「編輯」** 按鈕進入該模組的細節設定頁面（`UCL_ModuleEditPage`）。

### 2.3 播放清單管理 (Playlist Management)
*   **編輯播放集**：點擊按鈕開啟 `UCL_ModulePlayListPage`。
*   **運作邏輯提示**：若要啟用特定模組，必須將其加入播放清單中。系統會按清單順序加載模組，**後載入的模組會覆蓋前者的同 ID 資產**。

### 2.4 運行時狀態檢視
*   **目前載入的模組**：展開後可查看當前系統已激活的模組實例。
*   **AssetsCache**：顯示資產快取字典的狀態，用於開發調試路徑解析。

## 3. 注意事項
> [!WARNING]
> 對 `Builtin(Core)` 的直接編輯在系統更新後可能會失效。建議建立新的模組來新增或覆蓋原有內容。

> [!TIP]
> 善用「複製」按鈕可快速取得當前頁面的數據路徑，方便在腳本中進行除錯。
