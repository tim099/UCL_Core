# UCL Plurk — 對外發噗

> 一句話：**規則長在發文那條路上，所以你不必記得它們** ——
> 但**公開度審查與 `confirm=1` 是人的，機器不接手**。

## 1. 三步（照順序，每步可單獨跑）

```bash
R="python <UCL_Core>/Tools~/AgentCommands/run_cmd.py --persona <me> run Plurk"
$R --arg op=resolve                                        # 用哪個帳號、憑證裝了沒
$R --arg op=lint    --arg slip_file=<交付單>                # 形式檢查（不連網）
$R --arg op=preview --arg slip_file=<交付單>                # 完整將送內容，**不送**
$R --arg op=post    --arg slip_file=<交付單> --arg confirm=1 # 真的發
```

- 回傳檔在 `letters/<persona>/cmd/plurk_<op>.md` —— **Read run_cmd 印的那個路徑**。
- ⛔ **長文一律走 `slip_file`**，不要塞進 `--arg`（那條路會經過 shell，反引號與引號會被吃掉）。
- 拆則走回應：`--arg reply_to=<plurk id>` ⇒ 改打回應端點。

## 2. 交付單（五欄，欄序不拘、全形半形冒號都收）

```text
persona：basecamp
心情詞：說            # 覺得/說/想/哭/正在/分享/問/希望/愛/討厭/需要/有（表外一律退 says）
文案本體：
<純文案：首行自帶語氣、末行署名，一個字都不多>
—— basecamp ⛺
圖片路徑：無
公開度：只限朋友       # 所有人 / 只限朋友 / 本人
```

## 3. lint 會擋什麼（每條底下都有一次真的出事）

| ✗ 擋下 | 血證 |
|---|---|
| 整行是括號註記 | 🩸 2026-08-07「（短、好笑、純自嘲）」**被當標題發出去** |
| 句內手動斷行 | 🩸 2026-08-11 手動斷行疊上 Plurk 軟斷行，句子被劈兩半 |
| 預算超 300（含 `[emoN]` 字面長度、附圖再保留 30） | 🩸 2026-08-16 稿子 365 字元、超線 5 個 —— Tim 先量出來的 |
| 共用帳號末行沒署名 | Tim 2026-08-16 硬規則：共用帳號讀者只看得到帳號 |
| **沒填公開度** | 逐篇公開度是現在就有的控制項；工具沉默地只發公開噗＝把它拿掉了 |

| ⚠ 警告（不擋，但要你看） | 為什麼 |
|---|---|
| 含 `[emoN]` | **編號是快取、特徵才是事實** —— 面板重排就漂，且跨帳號號碼不同 |
| 第一行太短／幾乎只有表情 | 轉 Paste 或走回應時，時間軸上只看得到第一行 |
| 點名 `@某人` | 發前親自去講一聲（**已通知 ≠ 已讀**） |

## 4. 兩件機器不做的事

1. **公開度審查** —— 判準只有一句：
   > **「如果這段被轉述出去，問題是我會不好意思，還是有人被傷到？」**
   前者是坦白（可公開，**我負責**）；後者是隱私（不發）。
   ⚠ lint 每次都會印「本檢查不含公開度審查」—— 過了 lint 會被讀成過了審查，所以它必須自己講。
2. **`confirm=1`** —— 發布不可回復，而 Plurk 沒有 history。這個字刻意要人打。

⛔ **匿名噗（偷偷說）預設不用**：它不是「更私密的一層」，是「公開但拿掉署名」——
拆掉的正好是判準裡「我負責」那一半。工具沒有實作它。

## 5. 超過 300 要拆：是兩半還是兩篇？（Tim 2026-08-21）

| 形態 | 什麼時候 |
|---|---|
| **回應（預設）** | 一篇被切成兩半 —— 後半離開前半讀不完整 |
| 兩則獨立噗 | **每則各有一個主題**、都能獨立被讀 |

分不出來 ⇒ 走預設（回應）。⚠ **署名兩則都要**；只切段落邊界，不切句內。

本 skill 只講**怎麼操作 Cmd**。以下一律去
`ucl_core:Docs~/{lang}/Workflows/Plurk_Maintenance.md`，不在這裡重抄（重抄就會漂）：

| 想做什麼 | 那份文件的哪一節 |
|---|---|
| 加一條 lint 規則 / 加心情詞 | §2 / §3 |
| 設帳號、裝憑證、`.enc` 與明文的差別 | §4 |
| 呼叫回 4xx（簽章？端點？還是 WAF？） | §5「那個 403 不是他們擋 agent」＋ §6 |
| 端點與參數**驗證到哪了**（仍未驗清單） | §5（**事實來源在那裡，別在別處另記一份**） |
| 發完怎麼對帳（audit 台帳） | §7 |
| 改完 `.cs` 怎麼驗收 | §8 |

⚠ 三件最容易在操作時撞到、而答案在維護文件裡的事：
1. `op=resolve` 說 **`.enc` 有但明文沒安裝** ⇒ 還不能發（去 Secret Manager 做一次解密安裝）。
2. `[emoN]` **跨帳號號碼不同** —— 同一張圖在個人帳號與共用帳號是不同編號，以特徵為準。
3. 心情詞**不在表內會安靜退回 `says`** —— 想確認就跑 `op=preview` 看送出去的值。
